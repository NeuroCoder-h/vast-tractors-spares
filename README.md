# Field Essentials Investments — Website Starter

This is a dependency-free starter website built from the information visible on the supplied business card.

## Files

- index.html — website structure/content
- style.css — design and responsive layout
- script.js — mobile navigation, year and starter enquiry form
- assets/ — place for the company's real logo/photos later

## Run it

The simplest option:

1. Open the folder.
2. Double-click `index.html`.

For development in VS Code, install the Live Server extension and choose:
`Open with Live Server`

## Important before publishing

Confirm these details with the business:
- official logo
- official email address
- WhatsApp number (if any)
- opening hours
- exact spare-parts categories
- product/model list
- real company/warehouse photos
- whether the listed brands can be described as brands they officially represent

The current website does NOT claim that the company is an authorized dealer for any manufacturer.
